# Portfolio content guide

The portfolio UI is driven by the files in `data/`. Add content there first, then let the existing components render it.

## Add a project

Add one object to `data/projects.ts` with a unique `id` and `number`. Include the context, problem, technical approach, measurable results, tools, and evidence. The Work selector, case-study panel, tool wall, and CLI context update from this data automatically.

## Add a skill

Add a skill object inside the appropriate group in `data/skills.ts`. Use an existing proficiency value so the visual language stays consistent. New skills automatically appear in the Lab tool wall.

## Add experience

Add an object to `data/experience.ts` with a unique `id`, summary, responsibilities, and technologies. The timeline and technology tags are rendered from the array.

## Update personal details

Edit `data/profile.ts` for the name, role, location, links, availability, proof points, and résumé path.

## Deployment notes

Run `npm run lint` and `npm run build` before deploying. Static content is generated by Next.js and the site does not require a database or runtime content service.
